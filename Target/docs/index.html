Architecture Overview

Land replaces VS Code's Electron stack with a modern, high-performance architecture:

  • Mountain ⛰️

    Manages Window, File System and Process

    Rust/Tauri native backend

  • Cocoon 🦋

    Runs VS Code Extension via Effect-TS

    TypeScript extension host

  • Wind 🍃

    Re-Implementation of VS Code Workbench

    TypeScript UI service

  • Sky 🌌

    Renders the Editor Interface

    Astro UI component

  • Air 🪁

    Update, Download and Crypto Signing

    Rust background daemon

  • Echo 📣

    High-Performance Work-Stealing Executor

    Rust task scheduler
