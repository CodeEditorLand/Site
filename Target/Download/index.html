Telemetry Policy

Full disclosure on what Land collects — and what it does not.

No Telemetry by Default

Disabled 

Production builds ship with telemetry completely disabled. The Telemetry Cargo feature flag is not in default features — it must be explicitly opted in at compile time.

Default features: ExtensionHostCocoon, MistNative, AirIntegration. No Telemetry.

No Crash Reports

Disabled 

No crash reporter IDs, no external error reporting endpoints. Errors stay local. No crashReporterId in product.json.

Code-OSS base: CC0 licensed, no Microsoft telemetry endpoints.

No Phone Home

Disabled 

No usage data collection, no analytics endpoints, no DO_NOT_TRACK needed — telemetry simply does not exist in the build.

Zero-Cost No-Ops

Active 

When telemetry is disabled, all tracing, metrics, and spans compile to zero-cost no-ops. No runtime overhead whatsoever.

Rust #[cfg(feature)] gates eliminate dead code at compile time.

Optional OpenTelemetry

Optional 

Opt-in compile flag enables local OpenTelemetry tracing, metrics collection, and distributed spans. All data stays on your machine.

Enable with: cargo build --features Telemetry. Sub-features: MetricsCollection, DistributedTracing.

Local Effect-TS Telemetry

Active 

Cocoon extension host uses Effect-TS TelemetryService for internal metrics and spans. No external transmission — used for RPC instrumentation and bootstrap timing.

TelemetryMock layer available for testing (all no-ops).

Deployment Strategies

Four deployment modes from development to production.

Development (Hot-Reload)

Tauri dev mode with Sky dev server on localhost:9999. Live reload on file changes for rapid iteration.

bash Maintain/Dev-Mountain.sh
Hot-ReloadSky Dev Serverlocalhost:9999No Bundling

Debug Build

Three debug profiles with profile-specific bundling. Browser, Mountain, and Electron variants with tauri build --debug.

bash Maintain/Debug/Build.sh --profile debug-mountain
3 ProfilesDebug SymbolsConfigurable PortFile Watching

Production Release

Mountain workbench with full bundling, clean build, production NODE_ENV, and RUST_LOG=info. Signed and packaged.

bash Maintain/Release/Build.sh --profile production
Full BundleClean BuildPGP SignedRUST_LOG=info
