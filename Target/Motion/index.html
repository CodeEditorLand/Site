/THE SPECIMENS

What each motion explains, and the artifact that shows it

A motion is a sentence about a change of state. If the change can be described without the motion, the motion is decoration - so every class below is shown on the thing it is for, and the register beside it prints what the class costs and what it refuses.

# THE FOLD, IN FOUR RULES / KEPT / 04 OPEN CLOSE
  1. 01 The leaves move and the box does not ↳ The space is claimed in one frame when `[open]` flips, and the leaves arrive into it 24ms apart. A box that grew would reflow every band under it. 200 MS
  2. 02 The stagger stops at six ↳ A forty-leaf fold arrives as six and a run. Forty steps would take a second, and the last leaf would land after the reader had started reading the first. 24 MS
  3. 03 The words crossfade instead of swapping ↳ OPEN and CLOSE sit in the same grid cell and one fades as the other arrives, so the summary cannot jump when the state changes. 320 MS
  4. 04 Nothing opens on load ↳ No details on the site carries `open` in its markup, so the arrival rule cannot match until a reader asks for it. NEVER

/THE SEQUENCES

Four state changes this document performs, and one it cannot draw

A state machine is not a process: the nodes are conditions a record is in, and the edges are the motions that carry it between them, with the interval each costs. The last sequence on this page is the honest one - a transition whose state nothing in the markup sets, so its motion has no name and its interval has no figure.

/THE FOLD

One interaction, three sizes

The fold is the class this layer was built around, and it is the one that has to survive its own adverse states: a short fold, a fold longer than its frame, and a fold with nothing behind it. All three are the same band, the same leaves and the same grammar - what changes is what the world gave them.

/THE ARMS

Which states move, and which must not

Half of a motion language is the list of things it refuses to animate. An absence is a fact, a stale reading is a fact, a refusal is a fact - and a page that animated any of them would be decorating the truth instead of stating it. Nine arms, and only two of them move.

Nine adverse states and the motion each one gets. Seven of them get none, which is the design: an absence, a stale reading and a refusal are facts, and a fact that moved would be a claim the page cannot support.
STATE MOTION WHY
EMPTY NONE The band states what would be here and why it is not. A page that animated its own emptiness would be decorating an absence.
LOADING SKELETON, THEN RESOLVE 320MS The skeleton is printed, not pulsed. The one motion is the record that ends the wait, arriving on the resolve curve.
PARTIAL NONE UNAVAILABLE is a fact about a fact. There is no state change to explain, so nothing moves.
ERROR INTERRUPT 150MS One 2px offset, once, after the field loses focus - and never while the reader is correcting it.
STALE NONE The age is printed and the last known value stays visible. A stale figure that pulsed would be pretending to be live.
TOO MUCH FOLD 200MS, IF IT IS FOLDED The count is printed and the run scrolls in its own frame. The design does not animate the fact that there are two hundred.
TOO LONG NONE A value that does not fit wraps inside its own cell. Nothing is clipped, so nothing has to be revealed on hover.
MISSING NONE A tombstone is a printed row: the mark, the name, what it was. A record that faded out would read as a record that was never there.
DENIED NONE The surface states what it is and who may see it. A lock that shakes is a lock asking for attention it has not earned.

SOURCE: DESIGN-BRIEF.MD 7 A STATE THAT MOVED WITHOUT A CHANGE WOULD BE A CLAIM THE PAGE CANNOT SUPPORT

/THE REFUSALS

What this layer will not do, and why

Eight prohibitions, each one a rule a later card would otherwise be free to break by accident. They are printed here rather than kept in a comment because a design system's refusals are as much a part of it as its values.

A FOURTH INTERVAL:
THREE INTERVALS, THREE CURVES A class that needs another duration is a class whose state change has not been named yet.
A LOOP:
NO PULSE, NO SHIMMER, NO BLINKING CARET A loop continues without a state change, which is the first line of the register law's prohibition list.
AN ENTRANCE:
NOTHING ANIMATES AT FIRST PAINT No `<details>` on the site carries `open` in its markup, so no rule here can fire before a reader asks for it.
LAYOUT MOTION:
TRANSFORM AND OPACITY The one reflow is the fold's space, claimed in a single frame at the moment of the request - because a box that grows is a layout animation.
A SPINNER:
A SKELETON IN THE RECORD GRAMMAR A spinner says something is happening. A skeleton says what, and leaves the reader a legible statement if the wait never ends.
A SHADOW OR A SCALE:
NOTHING LIFTS, GROWS OR BLURS A slip does not zoom, a card does not lift. The paper has no depth, so nothing may pretend to leave it.
MOTION ON STATIC CONTENT:
NAME THE STATE CHANGE OR DO NOT WRITE THE RULE A paragraph is not loading and a heading is not hovered. That is the whole test, applied to every rule in the family - and a rule that cannot name the state change it answers is a decoration, which is what the test exists to catch.
A REDUCED-MOTION FALLBACK THAT LOSES A STATE:
THE END STATE, IN ONE FRAME A reader who asked for less motion is never shown less of the document. The handover is the one class switched off rather than shortened.

EVERY REFUSAL NAMES THE RULE IT PROTECTS NONE OF THEM IS A PREFERENCE

# NOTE_01 / REDUCED MOTION

↳ Every rule in the family declares its end state unconditionally and gates only its interval, so a reader who asked for less motion gets the same document in one frame. The page handover is the one exception and it is not an exception to the promise: it is switched off at the source (`navigation: none`), because a snapshot transition that runs in 0.01ms still paints two documents in one frame, and that reader is better served by the navigation they already know.
