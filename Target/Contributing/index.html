Contributing

Code Editor Land is open source and welcomes contributions from everyone. Here is how to get involved.

Contributing Guide→

Read the full CONTRIBUTING.md on GitHub for detailed instructions on setting up the development environment and submitting changes.

Good First Issues→

Browse issues labeled "good first issue" to find approachable tasks for new contributors.

How to Contribute

  1. 1

    Fork and Clone

    Fork the Land repository on GitHub and clone it locally with submodules: 

    git clone --recurse-submodules https://github.com/YOUR_USERNAME/Land.git
  2. 2

    Set Up the Environment

    Install Rust (1.95.0+), Node.js, and pnpm. Then run: 

    cd Land && pnpm install && cargo build
  3. 3

    Make Your Changes

    Create a new branch, make your changes, and follow the PascalCase naming convention used throughout the project.

  4. 4

    Submit a Pull Request

    Push your branch and open a pull request against the Current branch. Describe what you changed and why.

Elements Architecture

Code Editor Land is built from 15 modular Elements — self-contained components that provide specific functionality. Each Element lives in its own GitHub repository and can be developed independently.

Mountain 🏔️ Native backend Cocoon 🦋 Extension host Wind 💨 UI services Sky 🌤️ UI components Air 🌬️ Daemon sidecar Echo 🔊 Task scheduler Common 📦 Core library Vine 🌿 gRPC protocol Rest ⚡ JS bundler Output 📤 JS artifacts Mist 🌫️ WebSocket Grove 🌳 WASM extensions SideCar 🤖 AI/ML Worker ⚙️ Web workers Maintain 🔧 CI/CD scripts

Each Element has its own README with architecture details. Find them in Land/Element/

Ways to Contribute

Code 💻

Fix bugs, implement features, or improve performance in Rust or TypeScript.

Documentation 📖

Improve guides, add examples, or translate existing documentation to other languages.

Testing 🧪

Write tests, report bugs, or help reproduce and triage existing issues.

Design 🎨

Contribute UI/UX improvements, icons, or visual design work for the editor or website.
