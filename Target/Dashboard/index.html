# 04

Telemetry Architecture

01

Disabled   Feature Gated  

Absent from the binary. Not just disabled.

Telemetry  and tracing sit behind named Rust  feature gates. The build profile decides what is compiled in; nothing is emitted unless a specific feature path is enabled.

02

Optional  

Opt-in OpenTelemetry. Your infrastructure only.

Distributed traces for a deployment are opt-in: enable with cargo build --features Telemetry.Local-only OTEL  tracing, metrics and spans. No external transmission; all data stays on your infrastructure.

03

Active  

Extension host timing. Stays in the process.

Cocoon uses TelemetryService for internal RPC and bootstrap timing; the data is used for performance diagnostics only.All of it stays local, and a TelemetryMock layer is available for zero-overhead testing.
