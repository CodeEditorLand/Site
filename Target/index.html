# OBSERVATION_01 /PROOF

What the editor actually is.

Native speed. VS Code compatibility. No Chromium, no compromises.

A native code editor with the soul of VS Code - and none of the browser. Built on Rust and Tauri, compatible with the extensions you already use.

# 01

Native services where they count.

Heavy editor work runs natively, not trapped in a web view. Window management, file I/O, and terminals are native Rust services - no serialized JSON IPC bridge.

# 02

Unmodified extensions, no fork path.

Your VS Code extensions run unmodified - no forks, no rewrites. A compatibility host implements the VS Code extension API surface.

# 03

Fibers, not Promises.

Failures are typed, traceable, and cancellable - one supervised fiber never takes down the rest of the editor.

RUNTIME PATH

  1. 01MountainNative Rust backend: files, terminals, processes and gRPC IPC - no Electron main process.
  2. 02CocoonExtension host: unmodified VS Code extensions on the VS Code API surface.
  3. 03SkyAstro UI in the operating system WebView; Tauri events bridged to the workbench APIs.
  4. 04WindEffect-TS workbench services, one typed layer stack per runtime target.

# CLASSIFICATION_01 /WHAT RUNS

Under the Hood

Each element replaces one piece of the Electron stack. All inspectable in source.

The product the elements compose: Rust and Tauri with no Electron, VS Code compatibility with unmodified extensions, native across macOS, Windows and Linux, under CC0.

# MOUNTAIN_01

⛰️

→Mountain

  • Native Rust Backend
  • Tauri
  • Replaces Electron Main Process
  • SOURCE

Native Rust and Tauri backend. Implements the Common service traits: files, terminals, dialogs, processes, keychain. Hosts the gRPC server for the extension host and sidecars. Manages application state and sidecar lifecycle. Replaces the Electron main process. Active.

# COCOON_01

🦋

→Cocoon

  • Extension Host
  • Unmodified VS Code Extensions
  • Effect-TS Services
  • SOURCE

Node.js extension host. Runs existing VS Code extensions unmodified on the full VS Code API surface. Every extension runs in its own supervised Effect fiber. Crashes are trapped at the supervision boundary. Replaces the single-threaded extension host. Platform-native sandboxing planned.

# SKY_01

🌌

→Sky

  • Visual UI Layer
  • Astro Components
  • Three Workbench Layouts
  • SOURCE

Declarative UI layer built on Astro. Renders the editor interface in the OS WebView. SkyBridge routes Tauri events to VS Code workbench APIs. Conditional dynamic imports keep the bundle target-specific. Workbench layouts for Browser, Mountain-native, and Electron. Active.

# WIND_01

🍃

→Wind

  • Workbench Services
  • Effect-TS Layers
  • Native Bridges
  • SOURCE

Effect-TS service layer. Recreates the VS Code workbench environment inside the Tauri WebView. Typed Tauri commands replace Electron's untyped JSON IPC bridge. Layer stacks for Tauri, Electron compatibility, and isolated tests. Active.

# VINE_01

🌿

→Vine

  • gRPC Backbone
  • Contract-First
  • .proto Definitions
  • SOURCE

The gRPC backbone of Land. Proto/Vine.proto is the canonical contract between elements. Generates type-safe Rust clients and servers, plus a TypeScript mirror for the extension host. Connects Mountain, Cocoon, Air, and Grove. Active.

# GROVE_01

🌳

→Grove

  • WASM Sandbox
  • Wasmtime Runtime
  • Capability-Based Isolation
  • SOURCE

Rust and WASM extension host. Wasmtime sandbox: an extension can only touch what is explicitly granted. Same VS Code API surface as Cocoon. gRPC, IPC, direct WASM calls, or Mist transports. Complements Cocoon's Node.js path. Active.

# AIR_01

🪁

→Air

  • Background Services
  • Downloader
  • Workspace Indexer
  • SOURCE

Persistent Rust daemon. Updates, downloads, signing, and health checks outside the main window. Staged updates with automatic rollback. Warm file index across sessions. Replaces restart-to-update and cold-start indexing. Active.
