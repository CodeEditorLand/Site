Local-First

Local-First Account

Like a SaaS control panel that runs on your machine. Zero cloud dependency. The website communicates directly with the Air Daemon inside Land/Element via local-first protocol. Configure, update, rebuild, and deploy your editor entirely from this console.

Included

  • Direct Air Daemon connection to Land/Element 
  • Launch builds directly through the website console 
  • Deploy changes directly to the application 
  • Full editor configuration and settings management 
  • 1:1 parity with VS Code server features and settings 
  • No cloud login required. Complete offline operation. 
  • Bake the portal directly into the editor as embedded SaaS 

Capabilities

JWT developer certificates 
Mutual TLS authentication 
CRDT state synchronization 
Team management (fully local) 
Certificate authority management 
WebSocket live connection 
Local RBAC policies 
Encrypted local backup 
Protocol:mTLS / CRDTs / WebSocket
Settings ManagedIncluded in all tiers
